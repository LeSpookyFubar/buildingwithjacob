Before you start

A clear scope, by design.

What do I need to run it?

A current desktop browser with Web Crypto and JavaScript enabled. Extract the download and open index.html. If local-file restrictions apply, run a local static server using Python. Node 20+ is optional for automated checks; Python 3.10+ is optional for the separate EONET exercise. No paid API or hardware is required.

Is this satellite telemetry from NASA?

No. Core scenarios use original synthetic ground station records. The separate optional exercise can retrieve natural event metadata from NASA EONET and document its provenance. That metadata is not spacecraft telemetry. This is an independent BuildingWithJacob educational product, with no NASA affiliation or endorsement.

Does the AI mission test a real model?

No. It flags specified instruction strings in fictional data so you can practice treating source text as untrusted. The workbook includes a separate optional human-reviewed critique exercise. No real model is called or assessed by the app.

Can I use the reports in a portfolio?

Yes. Publish your own notes and analysis while clearly saying the case is simulated. You may adapt the source for personal and internal learning. The kit files and answer keys cannot be redistributed or resold.

Where does my data go?

The core workstation makes no network requests. Notes remain in memory unless you explicitly enable browser saving or export a backup. The optional EONET Python script connects to its fixed official endpoint only when you choose live mode.

What about support, updates and refunds?

This is a fixed-scope version 1 download. There is no subscription or lifetime-update promise. The seller must publish a support contact and refund terms at checkout before opening sales. Try the free sample first to check the workflow and browser compatibility.
